# Приложение для детского сада (Курсовой проект)

**Автор:** Бритвина Александра
**Группа:** 25-КБ-ПИ2
**Технологии:** C#, Windows Forms, .NET Framework 4.7.2

## ⚙️ Основной функционал
* **Для родителей:** просмотр расписания, посещаемости, оплата услуг, история платежей, просмотр уведомлений.
* **Для воспитателей:** просмотр воспитанников и информации о них, отметка посещаемости, редактирование расписания, отправка уведомлений родителям.
